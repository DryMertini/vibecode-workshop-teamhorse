# Optional tools, introduced when needed

| Tool | Use it when |
|---|---|
| IDE / editor | You need to inspect files, compare changes, run/debug code or use an integrated agent |
| Design tool | You need to compare visual alternatives and agree a reference before implementation |
| MCP connection | Your agent needs access to a specific external tool or source; inspect its permissions and use your own authorised account |
| Skill | You have a repeatable task worth packaging as reusable instructions |
| Orchestrator | Coordinating many real sessions has become a problem that manual handoffs no longer solve |

The basic workshop workflow needs Git, a coding agent, a browser and a reachable app. Extra integrations do not replace acceptance criteria, independent review or your judgement. Do not install an unfamiliar integration just because it appears in a list.

Provider documentation: [Codex CLI](https://learn.chatgpt.com/docs/codex/cli), [Claude Code](https://code.claude.com/docs/en/quickstart), [GitHub CLI](https://cli.github.com/manual/). Follow the current official instructions for your platform/account. Tool availability and pricing are not supplied or promised by this starter.
